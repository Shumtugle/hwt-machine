Скачать циферблат

Один файл на циферблат, на русском. Установите его любым приложением, которое умеет отправлять файл циферблата на часы.

Что делает машина

Часы читают компактный контейнер: разметку в protobuf, таблицу картинок и сами картинки. Машина пишет все три части и умеет прочитать любой циферблат обратно, чтобы показать, что внутри.

Контейнер байт в байт

Запись и чтение пересобирают существующие циферблаты байт в байт: заголовок, разметку, таблицу картинок, картинки со сжатием повторов.

По видимым чернилам

Цифры, прописные и значки ставятся по своим видимым пикселям, а не по метрикам шрифта, поэтому строки сходятся там, где ждёт глаз.

Вместе со временем

Метки по рамке, стрелки из света, уровни, льющиеся по экрану: это картинки, которые выбирают час, минута и секунда.

Любой язык

Дни недели и месяцы берутся из словаря; длинные слова сами ужимаются до своей карточки.

Сборка проверяет себя

Превью рисует симулятор, читающий готовый пакет, а карточка, задевшая рамку, останавливает сборку.

Открытые заметки

Виды элементов, источники данных и цели касаний записаны в заметках о формате, проверенные и нет.

Собрать самому

Нужны Python 3 и Pillow. Шрифты и их лицензии лежат в репозитории.

# циферблат из описания, по файлу на язык, в dist/
python3 tools/build.py faces/duo/face.json

# прочитать любой циферблат: разметка, картинки, отрисованный экран
python3 tools/inspect.py some-face.hwt --images out/ --render screen.png

# тесты
python3 -m unittest discover tests
