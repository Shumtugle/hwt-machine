What the machine does

The watch reads a compact container: a protobuf layout, a table of images and the images themselves. The machine writes all three, and reads any face back to show what is inside.

Byte-exact container

Writer and reader rebuild existing faces byte for byte: header, layout, image table, run-length images.

Ink alignment

Digits, capitals and symbols are placed by their visible pixels, not by font metrics, so lines meet where the eye expects.

Running second

The watch only offers the tens and units of a second. Two layers of pictures still move one mark around the frame.

Any language

Weekdays and months come from a locale file; long words shrink to fit their card on their own.

Self-checking build

Previews are drawn by a simulator reading the finished package, and cards that would touch the frame stop the build.

Open notes

Element kinds, data sources and tap targets are written down in the format notes, verified or not.

Build it yourself

Python 3 with Pillow. Fonts and their licences are in the repository.

# every locale of Vibe into dist/
python3 faces/vibe/build.py all

# read any face: layout, images, a rendered screen
python3 tools/inspect.py some-face.hwt --images out/ --render screen.png

# tests
python3 -m unittest discover tests
